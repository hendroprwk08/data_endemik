# 🌿 Data Hewan dan Tumbuhan Endemik Indonesia

## Deskripsi
Repository ini menyediakan dataset komprehensif tentang **hewan dan tumbuhan endemik Indonesia**. Data dikumpulkan dari berbagai sumber terpercaya dan dirancang untuk mendukung pembelajaran serta penelitian tentang kekayaan biodiversitas Indonesia.

## 📚 Tujuan
Proyek ini bertujuan untuk:
- Menyediakan akses mudah ke informasi spesies endemik Indonesia
- Menjadi media pembelajaran interaktif tentang API dan data JSON
- Mendokumentasikan kekayaan alam hayati Indonesia

## 🔗 API Endpoint
Data dapat diakses melalui endpoint berikut:

```
https://hendroprwk08.github.io/data_endemik/endemik.json
```

## 📖 Cara Penggunaan
1. Akses URL endpoint di atas untuk mendapatkan dataset
2. Parse data JSON yang diterima
3. Gunakan untuk keperluan pembelajaran, riset, atau aplikasi Anda

## 📝 Format Data
Dataset disimpan dalam format JSON yang terstruktur dengan baik untuk memudahkan integrasi dengan berbagai aplikasi.
